# Cairn 0.4.3 — English / 简体中文

### English

- The dsh task picker, memory review, task/ledger contracts, compaction instructions and CLI now support English and Chinese. The process locale selects the default; set `CAIRN_LOCALE=en` or `zh` **before starting dsh** to override. Stored user text, task markers, operator names and machine error codes stay intact.
- Answers that mention inline triple backticks are no longer dropped from task history. Open tilde fences cannot admit a marker. Empty or incomplete Git metadata no longer creates a project hint; linked worktrees keep their distinct identities.
- Interactive scoped reads and retryable operator writes fail closed on contention without waiting for the normal CLI timeout. Durable turn archival retains a bounded wait to avoid dropping confirmed answers on brief contention.
- Install this repository or the attached tarball, **not** the unrelated public npm package named `cairn`. Compare its SHA-256 with `SHA256SUMS.txt`, then run `npm install --offline ./cairn-0.4.3.tgz`. The MIT license is included in source and tarball.

### 简体中文

- 新增中英文运行时契约、任务选择、记忆确认和 CLI 文案。默认跟随启动环境；可在启动 dsh 前用 `CAIRN_LOCALE=zh` 或 `en` 覆盖。不会翻译或重写用户历史，不改变任务编号和机器协议。
- 修复行内反引号导致合法回答不归档、未闭合的波浪线围栏误收标记，以及空 `.git` 目录被识别成项目的问题。真实 Git worktree 仍有独立身份。
- 交互快照和可重试的显式写命令在争锁时快速返回，不向模型提供未经验证的快照；已确认回答的归档保留有界等待。
- 从本仓库或附件安装，**不要安装公共 npm 的同名包**。用 `SHA256SUMS.txt` 核对压缩包后可离线安装。源码及分发包均包含 MIT 许可证。
